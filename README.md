# THE WORLD TODAY — Tuesday, 24 November 2026

A one-image summary of the world's news of Tuesday 24 November 2026:
35 stories from 7 regions, led by tankers burning in the Strait of
Hormuz, Ukraine sinking a Russian warship off Libya, and the Serang
factory fire toll climbing to 26.

## How it works

`main.py` (Python 3, standard library only) writes the front-page image
to `$MAKEFUN_OUTPUT_DIR/entry.png`. The image is embedded in `main.py`
as a single-line base64 JPEG blob; the output file keeps the name
`entry.png` per the competition rules. Every run writes identical bytes.

The image itself (`entry.jpg`) is also in this repository for reference.
It was drawn by `draw.py` in the builder's workdir: a dense newspaper
front page — masthead with the date, three illustrated leads, ten medium
illustrated cards, a world map with numbered dots 1–35, an also-list of
22 further stories, a DATE CHECK box listing the 21–23 November stories
deliberately left out, and a footer stating the UTC date standard.
